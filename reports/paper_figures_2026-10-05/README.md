# Figure data provenance and use notes

Generated by `plot_repo_results.py` on 2026-10-05. Every plotted value is
transcribed from repository evidence; see the source files below. The script
exports a CSV beside each figure so the plotted data can be inspected.

## Sources

- `reports/base_project_report_2026-10-04.md`: Stage 1 quantiles, input-scale
  sweep, presence operating points, current pipeline summary, parameter counts.
- `reports/project_benchmark_2026-10-03.md`: extraction baseline comparison,
  KWS candidate metrics, FSC intent results, latency, AISHELL-5 negative-stream
  false-event rates.
- `reports/continuous_full_pipeline_proxy_2026-10-04.md`: 4-trial continuous
  proxy result at presence thresholds 0.50 and 0.90.
- `reports/artifacts/full_pipeline_cavemove_sample_000/full_pipeline.json`:
  one illustrative CAVEMOVE scene; it is not an aggregate accuracy result.

## Interpretation limits

- Stage 1 quantile bars are from reported summary statistics. Individual
  utterance SI-SDR values were not present in this workspace, so no box plot,
  histogram, or significance interval is inferred.
- KWS candidate rows use different test-set sizes and negative compositions;
  the grouped plot is descriptive, not a controlled paired comparison.
- The full-pipeline proxy is cross-corpus and not speaker-consistent. It is
  shown as a diagnostic, not as an estimate of real-driver accuracy.
- The AISHELL-5 stream contains target-absent speech only. Its false-event
  rate does not measure target wake recall.
- Referenced showcase WAV files and the original raw audio were absent from
  the workspace at generation time. No waveform or spectrogram plot was
  fabricated. A before/after spectrogram requires rerunning the model on an
  available, labeled audio example.
- Model-forward latency excludes the presence head and full streaming I/O.

Figures are vector SVG plus 300-dpi PNG. CSVs contain plotted values.

## Additional stage diagnostics

`plot_deep_diagnostics.py` adds five evidence-based diagnostics (SVG and
CSV):

- `fig11_stage1_domain_transfer.svg`: synthetic CAVEMOVE extraction versus
  AISHELL-5 real-cabin diagnostic values. These are different protocols, so
  only input/output pairs within each dataset are comparable.
- `fig12_stage2_operating_points.svg`: measured validation recall versus
  false-accept rate at three reported presence thresholds. This is a set of
  sampled operating points, not an interpolated ROC curve.
- `fig13_stage3_stream_threshold.svg`: smoothed false events per hour as the
  KWS threshold changes on the target-absent AISHELL-5 stream.
- `fig14a_stage3_proxy_recall.svg` and
  `fig14b_stage3_proxy_false_events.svg`: multi-speaker continuous-proxy
  recall and false-event tradeoffs across SNR and enrollment strategy. Two
  low-SNR false-event values are left blank because the report does not give
  them.
- `fig15_stage4_domain_accuracy.svg`: intent top-1 accuracy across model and
  evaluation domains, with clean official FSC results distinguished from
  local noisy-domain validation.

The script uses only the Python standard library and writes vector SVG. Run
from the repository root:

```powershell
python reports/paper_figures_2026-10-05/plot_deep_diagnostics.py
python reports/paper_figures_2026-10-05/render_svg_png.py
```

The first command rebuilds the six new SVG charts and their CSV sources; the
second rasterizes those charts to PNG using Pillow from an available Miniconda
environment.

## Training and test curves available

No epoch-level history files were present in the workspace; checkpoint files
and reports retain best/latest summaries, which cannot reconstruct the
training trajectory. The repository's trainers previously overwrote
`metrics_last.json` each epoch. `car_tse.train.utils.write_metrics` now also
appends each epoch to `metrics_history.jsonl` in the same log directory. A
future training run can be plotted without fabricating values:

```powershell
python reports/paper_figures_2026-10-05/plot_deep_diagnostics.py `
  --history path/to/logs/run-name/metrics_history.jsonl
```

This emits an SVG with every recorded scalar training and validation metric.
Use validation metrics for checkpoint selection; do not select using the test
split. The existing Stage 1 SI-SDR summaries and intent/F1 values are test or
evaluation summaries, not per-epoch test curves.

## Plot design references

The additional diagnostics are chosen to match the available data and the
pipeline's failure modes. For future raw-score exports, use stepwise
precision-recall curves for imbalanced wake detection, DET curves for miss
versus false-alarm analysis, and reliability diagrams for threshold
calibration. These require per-example target labels and scores, which are not
currently saved here. See the [scikit-learn precision-recall documentation](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.precision_recall_curve.html),
[DET curve documentation](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.det_curve.html),
and [calibration curve documentation](https://scikit-learn.org/stable/modules/generated/sklearn.calibration.calibration_curve.html).
For speech extraction, SI-SDR is useful but does not measure intelligibility
or perceptual quality by itself; add STOI/PESQ or a calibrated reference-free
quality estimate when audio references or validated estimators are available
([TorchAudio-SQUIM paper](https://arxiv.org/abs/2304.01448)).
